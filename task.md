# Проект «Электронное расписание»

Веб-приложение для управления расписанием учебных занятий в колледже. Позволяет преподавателям и администраторам создавать и редактировать расписание, а студентам — просматривать его в удобном виде. Система исключает накладки при бронировании аудиторий и контролирует загрузку преподавателей.

## Основные возможности

- **Студент**  
  Просмотр расписания по дате, преподавателю, предмету или аудитории (без права редактирования, авторизация не требуется).

- **Преподаватель**  
  Добавление, изменение и удаление только своих занятий. При конфликте по времени система выдаёт предупреждение, но решение принимает преподаватель.

- **Администратор**  
  Полное управление расписанием (любые занятия, переносы). Ведение справочников: преподаватели, предметы, аудитории. Управление учётными записями преподавателей.

## Технологический стек

| Компонент        | Технология             |
| ---------------- | ---------------------- |
| База данных      | PostgreSQL             |
| Серверная часть  | Golang (Fiber)         |
| Клиентская часть | Vue.js                 |
| Контейнеризация  | Docker, Docker Compose |

## Структура данных (основные таблицы)

- **teachers** – преподаватели (ФИО, логин, хеш пароля).
- **subjects** – учебные предметы (название).
- **classrooms** – аудитории (номер кабинета).
- **schedule** – расписание (дата, время начала/окончания, ссылки на преподавателя, предмет и аудиторию).  
  Действуют ограничения:  
  – Одна аудитория не может быть занята двумя занятиями одновременно.  
  – Один преподаватель не может вести две пары в одно и то же время.
